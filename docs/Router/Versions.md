# Versions

Pantheon Router has its own version number. It does not change when Pantheon changes, so the same Router pages can appear in more than one Pantheon documentation version.

The version picker at the top of the site lists Pantheon versions, not Pantheon Router versions. Use this table to find the pages for the version of Pantheon Router that you use.

| Pantheon Router | Pantheon documentation | Pages |
| --------------- | ---------------------- | ----- |
| 0.1 | `dev` | [Pantheon Router 0.1](https://pantheon.7kayoh.net/dev/Router/) |

## What each row means

- **Pantheon Router** is the version in `pesde.toml` of the package. `0.1` stands for every `0.1.x` release.
- **Pantheon documentation** is the version in the picker that has the Router pages for that version. When the Router changes in a way that breaks your code, its old pages stay in the older Pantheon documentation versions, and this table points to them.
- A row for a Pantheon Router version that is not released yet points to `dev`, which always has the latest pages.
